# TodoApp

Proyecto simple de lista de tareas pensado para la diplomatura Fullstack Developer de la UTN. Permite anotar pendientes rapidos, marcarlos como completados y eliminar los que ya no sirven.

## Pasos para iniciar la app

1. Instalar dependencias:

   ```bash
   npm install
   ```

2. Levantar el servidor de desarrollo (elige una opcion):

   ```bash
   npx ng serve
   # o
   npm run start
   ```

3. Abrir el navegador en `http://localhost:4200/`.
